# Autonomous Alpha Phase C: closed-loop research (NO LLM and NO code agent)

## What runs unattended

The existing `.github/workflows/ml_research.yml` cron is reused unchanged:
- Monthly full research: 3rd day at 07:41 UTC, includes bounded genetic explorer + research lab.
- Weekly research: Saturdays 08:23 UTC, includes forward prediction / matured-label collection, options-quote audit and deterministic reflection.
- No personal desktop, manual CLI, new paid API, self-modifying Python or extra GitHub workflows are required.
- Factory-plan's previous optional `--llm` is removed from that workflow. Phase C calls no LLM at all. The existing production scanner LLM budget is a separate system and is unchanged.

## Evidence pipeline

A. The Phase B Explorer preregisters immutable AUTO-* expressions. Phase C's
`factor_forward.py` reads those **already frozen** expressions, evaluates
them only on the latest point-in-time panel date (and only if registration
precedes that date), and writes an append-only snapshot of the 10 highest
and 10 lowest signal names. NEVER backfill historical predictions.

B. On subsequent research runs, factor predictions are scored only once
20-trading-day labels are available and their label_end date is **not later
than the evaluation date**. Missing labels stay PENDING. The outcome stored
is gross top-minus-bottom stock-relative return, NOT options P&L, net alpha,
or independent promotion proof.

C. `forward_options.py` reads ONLY existing archived option trade outcomes
and pre-existing observed option quotes. An option close counts as
quote-verifiable only if it is post-registration, observed, reliable,
reproducible, executable RTH, includes both entry and exit archived quote IDs,
and those quotes are from the correct days and contracts. Zero quote means
UNKNOWN, not a zero-return trade. Gross and net option outcomes are not
interchanged. The existing cost model omits some external fees. Records
without sufficient proof remain diagnostic only.

D. `reflection.py` reads the existing hypothesis DB, prospective stock
outcomes and verified real options observations; it generates bounded
research-only tasks and aggregate family priors. Only families with >= 6
distinct matured prediction dates can influence subsequent exploration
priority; these priors are shrunk to at most 2 pseudo-observations. The
Explorer uses prior reflection to reserve additional random exploratory
capacity when no economically confirmed alpha exists.

## Evidence separation and limits

- Real options-trade outcomes do NOT currently include the immutable AUTO
  factor ID plus pre-trade feature snapshot. They therefore CANNOT establish
  that a discovered factor caused or predicted the realized option return.
- No alpha is declared validated; no production promotion, order, position
  size, risk-limit change or market API request is made.
- Research metrics are monitored to guide additional falsifiable hypotheses;
  repeated adaptive selection increases multiple-testing risk, so independent
  prospective validation remains essential.
- No reflection report is allowed to set `alpha_validated: true`.
- Critical CI checks fail after preserving existing research outputs if
  the new evidence audit fails.
- New analysis introduces no LLM-token costs; ongoing existing upstream
  data and GitHub Actions runtime still have costs.

## Manual diagnostics, if wanted (NOT needed for ongoing operation)

    python -m modules.autonomous_alpha factor-forward --panel-cache /trusted/local/panel.pkl
    python -m modules.autonomous_alpha option-forward
    python -m modules.autonomous_alpha reflect
    python -m modules.autonomous_alpha status

Only use a trusted PIT panel pickle generated by the same CI job; Python
pickle files are unsafe when obtained from unknown sources.

## Next evidence milestone

When 26 or more independently quote-verifiable post-registration closes span
at least 20 distinct entry dates, the diagnostic cohort can be reviewed.
This does NOT by itself demonstrate profitable or attributable alpha. For
that, the scanner would have to register the factor signal and specific
option contract at decision time, before entry, and independently test
paired factors across sufficient market regimes. Until then all approvals
remain blocked.
